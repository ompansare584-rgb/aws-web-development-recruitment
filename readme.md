# Web Dev Recruitment Tasks - First Year (FY)
Submitted by: **Om Suresh Pansare** (B.Tech Computer Science, VIT Pune)

This repository contains all prerequisite tasks completed for the Web Development recruitment process. Each task has been built from scratch using modern web standards without external frameworks.

---

## 📂 Project Structure

- **`/portfolio`** → Task 1: Personal Portfolio Page (HTML5, CSS3, Vanilla JS)
- **`/landing-page`** → Task 2: SaaS Landing Page Clone (HTML5, CSS Grid, Flexbox, Pure CSS Hamburger Menu)
- **`/todo-app`** → Task 3: Interactive To-Do Web Application (Plain JavaScript & `localStorage`)

---

## 🚀 Tasks Overview

### Task 1: Personal Portfolio
* **Features:** Semantic HTML structure, fully responsive layout, light/dark mode toggle with `localStorage` persistence, CSS keyframe entrance animations, and high Lighthouse accessibility optimization.

### Task 2: Landing Page Clone (NovaCloud)
* **Features:** Pixel-accurate SaaS template replica.
* **Layouts:** Uses **CSS Grid** for features/pricing matrices and **Flexbox** for alignment.
* **Bonus:** Implemented a **pure CSS mobile hamburger menu** using the checkbox hack (zero JavaScript required).

### Task 3: Interactive To-Do Web App (TaskFlow)
* **Features:** Full CRUD operations (Add, Edit, Delete, Complete), dynamic status filters (All, Active, Completed), remaining items counter, and real-time state persistence using browser `localStorage`.
